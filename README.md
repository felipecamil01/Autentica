# Autêntica — demonstração de site

Site estático de apresentação para Autêntica Estética Automotiva, Foz do Iguaçu.

## Visualizar

Abra `index.html` no navegador ou execute `python -m http.server 8000` nesta pasta e acesse http://localhost:8000.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: visual responsivo.
- `script.js`: preparação de mensagem para WhatsApp.
- `hero.jpg`: fotografia ilustrativa.

Não exige instalação de dependências ou build. Para GitHub Pages, use a pasta raiz da branch `main`.

## Observações

Proposta independente, não é o site oficial da empresa. Identidade visual conceitual; contatos e serviços devem ser confirmados com a empresa antes do lançamento oficial. O formulário abre o WhatsApp e não envia mensagens automaticamente.
